# Time Tamer

A Telegram bot that converts time to your local timezone.

The primary instance is available as [@time_tamer_bot](https://t.me/time_tamer_bot),
but feel free to run your own ones if needed.

## Usage

Specify your timezone in Time Tamer's DM (e.g., `Europe/Nicosia`), and subscribe to time translations by submitting
`/translate_time_for_me` in the corresponding group chats.

As soon as the bot knows about your timezone, each time you mention time in
a group chat message, the bot will provide a clarification for it along with
additional translations to local timezones of the chat subscribers.
